# The Church of Titor · [churchoftitor.com](https://www.churchoftitor.com)

A satirical, in-universe site from the [Time Travel Institute](https://timetravelinstitute.com) about the John Titor legend.

The homepage is an in-browser **IBM 5100 emulator interface**, the machine at the center of the Titor story. The content pages are managed with Keystatic and Markdoc.

**Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, Keystatic CMS, Markdoc. Deployed on Vercel.

```bash
npm install
npm run dev
```
